# BPS Business Car — plateforme de vente, commande et location

Site statique (HTML, CSS, JavaScript) pour le Grand Katanga : Lubumbashi, Kolwezi, Likasi.
Aucune installation requise : ouvrez `index.html`.

## Fichiers
- `index.html` : structure de la page
- `style.css` : charte noir, or, blanc
- `data.js` : stock à vendre (`ROWS`) et locations (`RENT`) — **le fichier à modifier pour vos véhicules**
- `app.js` : recherche, filtres, devise USD/FC, location, liens WhatsApp

## À personnaliser
1. `app.js` : `WA` (numéro WhatsApp, sans « + ») et `RATE` (taux USD → FC).
2. `index.html` : email et numéro affichés dans le pied de page.
3. `data.js` : remplacez les véhicules d’exemple. Ajoutez vos photos plus tard (dossier `images/`).

## Publier avec GitHub Pages
Dépôt → Settings → Pages → Branch `main` / dossier `/ (root)` → Save.
